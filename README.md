# 🌦️ Weather App

A simple and elegant **React Weather App** built using **Vite**, **OpenWeatherMap API**, and **React Hot Toast** for notifications.  
It allows users to search for any city and view the current temperature, weather description, and country — all in real-time.

---

## 🧩 Features

- 🌍 Search weather by city name  
- 🌡️ Real-time temperature (°C)  
- ☁️ Weather condition and description  
- 🔔 Toast notifications for errors and alerts  
- 🎨 Responsive UI with clean, minimal design  

---

## 🛠️ Tech Stack

- **Frontend:** React (Vite)
- **API:** [OpenWeatherMap](https://openweathermap.org/)
- **Styling:** Tailwind CSS
- **Notifications:** React Hot Toast
